# Чек-лист для презентаций

Перед сдачей презентации проверьте её по всем пунктам. Эти требования обсуждаются на защитах и перечислены в руководстве, но дополнительная проверка не помешает. Качество презентации — один из критериев оценивания на каждом этапе, поэтому несоответствие требованиям может снизить баллы.

## Нужные слайды

- [ ] Титульный лист с названием проекта.
- [ ] Один слайд с составом команды и фотографиями.
- [ ] Слайд с описанием идеи.
- [ ] Слайд с референсами для проекта.
- [ ] Слайд со списком задач, необходимых для успешного завершения проекта.
- [ ] Слайд со структурными частями проекта и соответствующими элементами стека технологий.
- [ ] Слайд со ссылками на открытый репозиторий и публичную сборку для тестирования.
- [ ] Слайд с матрицей распределения ответственности — для нулевой версии и последующих этапов.
- [ ] Слайд с диаграммой Ганта — для нулевой версии и итоговой защиты.
- [ ] Слайд с графиками коммитов из GitHub — для нулевой версии и последующих этапов.
- [ ] Слайд с прогрессом: конкретные результаты, доля выполненной задачи и сравнение с предыдущей версией.
- [ ] Слайды с личным вкладом каждого участника — для нулевой версии и последующих этапов.
- [ ] Слайды со скриншотами основного функционала — для нулевой версии и последующих этапов.

## Финальная проверка

- [ ] На одном из слайдов чётко указан тип проекта: приложение, сайт, игра и так далее.
- [ ] Для каждого участника указано или сказано, что он сделал и в каком объёме.
- [ ] Все слайды, кроме титульного, пронумерованы.
- [ ] Весь текст читается и контрастирует с фоном.
- [ ] На слайдах нет больших объёмов текста.
- [ ] Все ссылки работают, а QR-коды сканируются.
- [ ] Система контроля версий, IDE и графические редакторы не входят в стек технологий.
- [ ] Использовано соотношение сторон 4:3 или 16:9.
- [ ] Презентация для сдачи сохранена в PDF либо в PPTX, если есть анимация.
- [ ] При преобразовании в PDF ничего не изменилось и не сместилось.

Залог успеха — не только красивые слайды, но и манера подачи. Скучный монотонный рассказ без интереса к происходящему может испортить впечатление. Кратко напомните, о чём проект и кто его делает, но не говорите «как мы уже рассказывали несколько месяцев назад».

- [ ] Выступление отрепетировано и укладывается в пять минут.
- [ ] Готово, вы восхитительны!
