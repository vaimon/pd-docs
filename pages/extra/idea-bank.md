# Банк идей

## Ассистент по главному корпусу ЮФУ

- **Держатель кейса:** ЮФУ.
- **Тип проекта:** веб-приложение.
- **Описание:** база знаний об институте, которая упрощает навигацию по главному корпусу ЮФУ и объясняет порядок оформления различных университетских документов.
- **Примеры использования:**
  1. Пользователь выбирает процедуру, например устройство на работу.
  2. Приложение показывает список кабинетов в порядке посещения и, возможно, перечень необходимых документов.
  3. При выборе кабинета приложение показывает его на плане этажа.
- **Контакт держателя кейса:** Telegram — `@cooliron`.
